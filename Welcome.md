# Welcome to Public

This is your public vault for open, sharable notes.

## Getting Started

1. Open Obsidian and select this vault
2. Use wikilinks like [[To Do List]] to connect notes
3. Explore the file explorer and graph view

## Folders

- [[Notes]] — General notes
- [[Projects]] — Active projects
- [[Archive]] — Archived content

## Tips

- Use **bold** and *italics* for emphasis
- Create [[quick-note]] links between related notes
- Use the command palette (Ctrl+P / Cmd+P) for all actions
